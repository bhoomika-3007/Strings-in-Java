Strings in Java
📌 Repository Overview

This repository contains Java programs focused on String handling concepts.
It is created to practice and demonstrate how Strings work internally in Java, along with commonly used String operations and methods.

This repository is useful for beginners, interview preparation, and core Java revision.

🛠️ Technologies Used

Programming Language: Java

IDE: Eclipse IDE

📘 Topics Covered

String creation and initialization

String immutability

String comparison

Common String methods

String manipulation techniques

Difference between String, StringBuilder, and StringBuffer
